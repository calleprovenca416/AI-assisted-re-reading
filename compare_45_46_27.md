Three of chat 45's four readings open the same point as one of chat 46's and one
of chat 27's, with much the same wager; the wagers built on them differ in
emphasis, most for firearms, where chat 45's is about how a remote demand
reaches a unit and chat 27's about which part of a model a unit can take up.

a related one in chat 27.

"The same point" is a judgment made by reading and checked by no one; the three
replies are in the folder for checking it. The limits: one paper, one run of
each chat, one model; chat 46's request asked for passages that careful readers
could read two ways, and chat 27's asked only for alternative readings.
